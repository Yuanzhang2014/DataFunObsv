Target estimation of nonlinear neuron networks using limited sensors
===
usage
---
* `neuron_nonlinear_Koopman_centerpoint_VER6.m` : Main script for estimation performance for the nonlinear neuron networks using limited sensors by Koopman operator.

* ` neuron_nonlinear.m`: Generate nonlinear neuron network system trajectories.

* `Lift_Koopman_X`: Create thin plate spline radial basis functions and lift original state data to higher-dimensional space
